004材质：物体的表面

第 3 课讲了形状（Geometry），这节课讲另一半——外观（Material）。同一个球体，披上不同的材质，可以是塑料、金属、玻璃、皮肤。

核心概念

材质 Material

定义物体表面的视觉属性——颜色、透明度、反光程度、金属感。Material 决定光线照到物体表面后"长什么样"。

PBR Physically Based Rendering

基于物理的渲染——现代 3D 引擎的标准。用几个物理参数描述材质，就能在各种光照条件下看起来真实。Three.js 的 MeshStandardMaterial 和 Godot 的 StandardMaterial3D 都是 PBR 材质。

金属度 Metallic / Metalness

0 到 1 的值。0 = 非金属（塑料、木头、皮肤），1 = 纯金属（金、银、铁）。金属表面的反射特性完全不同——它反射环境光，没有漫反射。

粗糙度 Roughness

0 到 1 的值。0 = 镜面般光滑（完美反射），1 = 完全粗糙（漫反射）。控制物体表面的"磨砂感"。

常用材质类型

Three.js特点适用
MeshBasicMaterial不受光照影响，纯色/贴图UI、线框、调试
MeshPhongMaterial经典光照模型，高光明显简单场景、塑料感
MeshStandardMaterialPBR 标准，物理真实推荐，通用
MeshPhysicalMaterialPBR 扩展，支持透明涂层等汽车漆、皮肤
ShaderMaterial自定义着色器，完全可控特效、辉光、程序化
Godot 对照：Godot 的 StandardMaterial3D ≈ Three.js 的 MeshStandardMaterial，都是 PBR。Godot 还有 ORMMaterial3D（遮挡-粗糙-金属打包贴图）。

PBR 两大核心参数

金属度和粗糙度是 PBR 最重要的两个参数，它们决定了材质的"性格"：

金属度=1, 粗糙度=0
镜面金属 — 铬球
金属度=0, 粗糙度=0
光滑塑料 — 瓷球
金属度=1, 粗糙度=1
磨砂金属 — 拉丝铝
金属度=0, 粗糙度=1
粗糙哑光 — 橡皮泥
// Three.js — PBR 材质
const mat = new THREE.MeshStandardMaterial({
  color: 0xcc8844,      // 基础颜色
  metalness: 0.9,        // 金属度：接近纯金属
  roughness: 0.2,        // 粗糙度：比较光滑
});

// Godot — StandardMaterial3D
var mat = StandardMaterial3D.new()
mat.albedo_color = Color(0.8, 0.53, 0.27)
mat.metallic = 0.9
mat.roughness = 0.2

你已经用过的材质

旋转地球 demo 里的三种材质：

// 1. MeshPhongMaterial — 地球本体（经典光照 + 贴图）
new THREE.MeshPhongMaterial({
  map: earthTex,              // 颜色贴图
  emissive: 0xffffff,         // 自发光（iSH 兼容方案）
  emissiveMap: earthTex,
  emissiveIntensity: 1.0,
  shininess: 15               // 高光锐度
});

// 2. MeshPhongMaterial + transparent — 云层（半透明）
new THREE.MeshPhongMaterial({
  map: cloudTex,
  transparent: true,           // 开启透明
  opacity: 0.85,               // 85% 不透明
  depthWrite: false            // 不写深度（避免遮挡问题）
});

// 3. ShaderMaterial — 大气辉光（自定义着色器）
new THREE.ShaderMaterial({
  transparent: true,
  side: THREE.BackSide,        // 渲染背面（从内部看）
  // 自定义 vertex/fragment shader...
});

自发光 Emissive

自发光让物体"自己发光"，不需要外部光源。常用于：霓虹灯、屏幕、岩浆、萤火虫。

// Three.js
const mat = new THREE.MeshStandardMaterial({
  color: 0x000000,              // 基础色（黑）
  emissive: 0x00ff00,           // 自发光绿色
  emissiveIntensity: 2.0        // 发光强度
});

// Godot
mat.emission_enabled = true
mat.emission = Color(0, 1, 0)
mat.emission_energy_multiplier = 2.0
技巧：在地球 demo 里，我们用 emissiveMap 让贴图在 iSH 上正常显示——这就是自发光的一个实际应用（虽然是 workaround）。

口头描述练习

🗣️ 做一个科幻场景：太空站走廊，怎么描述材质？

"地板用 StandardMaterial3D，albedo 深灰色，metallic=0.9，roughness=0.3——光滑的金属地板，能反射灯光。墙壁 albedo 白色，metallic=0.1，roughness=0.8——哑光塑料面板。天花板上的灯条用 emissive 发出蓝白色光，emission_energy=3.0，作为走廊的主光源。门框的金属边框 metallic=1.0，roughness=0.1——镀铬效果。控制面板屏幕上 emissive 显示绿色数据界面，加一个 albedo_texture 显示 UI 贴图。"

→ 你用 metallic、roughness、emissive 描述了整个场景的材质方案。这就是指挥 agent 布置场景的方式。
