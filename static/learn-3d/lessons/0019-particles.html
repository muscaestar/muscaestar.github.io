019粒子系统：火、烟和魔法

火不是 mesh，烟不是贴图，魔法爆炸不是动画——它们是粒子系统：成百上千个小图元，各自出生、运动、死亡，集体形成流动的效果。这是特效的基本功。

核心概念

粒子 Particle

一个最小的渲染单元——通常是面向相机的四边形（billboard quad），贴一张小图（火花点、烟雾团）。每个粒子有生命周期：出生 → 运动 → 死亡。

发射器 Emitter

生产粒子的源头。定义：在哪生成（点/球/盒/锥）、多快（每秒几个）、初始状态（速度方向、大小、颜色）。

生命周期属性 Lifetime / Over-Lifetime

粒子存活期间属性怎么变化。关键设计：属性不是固定值，而是曲线——大小随时间先涨后缩、颜色从白变灰、透明度淡出。"曲线调参"就是特效师的主要工作。

粒子的解剖

一个火焰粒子的一生：

  出生（emit）
    位置：发射器范围内随机
    速度：向上 + 少量随机扩散
    大小：0.2 ~ 0.4 随机
    颜色：亮橙
    寿命：1.5 秒

  存活（update，每帧）
    位置 += 速度 × dt
    速度 += 外力 × dt（浮力向上、轻微噪声扰动）
    大小：曲线 → 先涨到 1.5 倍再缩到 0
    颜色：曲线 → 橙 → 红 → 暗红
    透明度：曲线 → 最后 30% 寿命淡出

  死亡（kill）
    寿命耗尽 → 回收到粒子池（不销毁，复用）

核心属性一览

发射形状（Emission Shape）
粒子从哪生出来：点（火堆）、球（爆炸）、锥（喷气机）、盒（房间灰尘）、边缘（水花沿环线）
→ 火焰用点+小半径，爆炸用球，喷泉用锥
发射速率（Rate）
每秒生多少个。还有爆发模式（Burst）：瞬间生 100 个（爆炸），然后停止
→ 火焰持续 30/s，爆炸 burst 200 个
初始速度（Initial Velocity）
方向和大小，通常加随机范围。锥形发射 = 沿锥方向 ± 随机偏角
→ 烟花向上 20m/s ± 15° 偏角
力场（Forces）
持续作用在粒子上的力：重力（雨、雪）、浮力（火、烟）、风、涡流（旋涡）、阻力（空气）
→ 烟 = 浮力 + 风 + 阻力；瀑布 = 强重力
大小/颜色/透明度曲线（Over Lifetime）
特效的灵魂。烟：小→大 + 浓→淡；火：大→小 + 亮→暗；魔法：闪→稳→散
→ 90% 的"像不像"取决于曲线调得好不好
噪声扰动（Noise/Turbulence）
给速度加噪声场扰动——粒子不再走直线，像被气流吹得摇摆。烟和火必开
→ 就是第 17 课的 Perlin 噪声，用在速度场上
渲染模式（Render Mode）
billboard（永远面向相机）、stretch（沿速度方向拉伸，做速度线/雨丝）、mesh（粒子是小模型，做碎片）
→ 火花 billboard，雨 stretch，爆炸碎石 mesh

经典配方

效果发射关键曲线秘诀
火焰点，30/s，向上速度大小先涨后缩，橙→红→黑噪声扰动 + 多层叠加（内焰亮黄、外焰橙红）
烟雾小半径，10/s，慢速向上大小持续涨，透明度慢淡出大噪声扰动 + 半透明贴图 + 长寿命
爆炸球，burst 200 个初速快衰减也快，亮闪→暗三层：闪光（瞬间亮球）+ 火花（高速粒子）+ 烟（慢速残留）
雨大盒（覆盖视野），500/s恒定速度向下stretch 渲染沿速度拉长 + 相机跟随发射器
魔法轨迹沿运动路径发射颜色循环渐变，拖尾渐隐trail 渲染（粒子间连线）+ 发光后处理
尘埃/氛围房间大小的盒，3/s几乎不动，微微飘极少极淡，存在感越低越好——只是打破死空气

CPU 粒子 vs GPU 粒子

CPU 粒子GPU 粒子
更新每帧 CPU 算每个粒子位置GPU shader 算，CPU 只管发射
数量级几百~几千几万~百万
交互可以（碰撞、拾取、脚本控制）难（数据在 GPU，读回很贵）
适用少量但需要交互（技能特效）纯观赏（雨、雪、氛围尘埃）
Godot 的 GPUParticles3D 是默认选择，CPU 粒子（CPUParticles3D）只用于需要碰撞的场景。粒子的"更新逻辑"写在 shader 里——位置 = f(初始值, 时间)，不需要存状态，这就是 GPU 粒子能跑到百万级的秘诀。

性能要点

优化做法
粒子池死亡的粒子不销毁，回池复用——避免频繁分配内存
合批所有粒子一个 draw call（共享材质，数据打包进一个 buffer）
贴图集多张粒子小图合在一张大图上（atlas），避免切换纹理
LOD远处粒子系统降速率或整个关闭（又是 LOD 思想）
半透明排序粒子半透明要排序渲染，乱序会闪——按深度排序是开销大头

Godot 实现

# Godot 4：GPUParticles3D 节点
var particles = GPUParticles3D.new()
particles.amount = 64
particles.lifetime = 1.5
particles.emitting = true

var mat = ParticleProcessMaterial.new()
mat.direction = Vector3(0, 1, 0)         # 向上
mat.spread = 15.0                        # 偏角
mat.initial_velocity_min = 2.0
mat.initial_velocity_max = 4.0
mat.gravity = Vector3(0, 2, 0)           # 浮力（负重力）
mat.scale_min = 0.2
mat.scale_max = 0.5
# 曲线：大小随生命变化
var curve = Curve.new()
curve.add_point(Vector2(0, 0.5))
curve.add_point(Vector2(0.3, 1.5))
curve.add_point(Vector2(1, 0))
mat.scale_curve = curve

particles.process_material = mat
add_child(particles)

口头描述练习

🗣️ 篝火特效的完整配方怎么描述？

"四层叠加：1) 火焰层——点发射 40/s，初速向上 2~4m/s，浮力 2，大小曲线先涨 1.5 倍再缩到 0，颜色橙黄→橙红→暗红，噪声扰动 0.5，billboard 渲染用火焰序列帧图。2) 火星层——burst 偶发，初速 5~8m/s 带随机偏角，受重力，亮橙小点，寿命 2 秒拖出抛物线。3) 烟层——火焰上方 0.5m 发射，慢速上浮，大小持续涨 3 倍，深灰半透明，大噪声扰动，寿命 4 秒。4) 光晕层——一个静态 billboard 贴径向渐变图，叠加 additive 混合，透明度随火焰强度轻微脉动。GPU 粒子，全部一个 atlas 贴图，远处降发射速率。"

→ 你用了分层叠加、发射参数、浮力、曲线、噪声、序列帧、additive 混合、性能 LOD。这就是专业级的篝火特效描述。
