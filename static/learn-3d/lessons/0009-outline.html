009描边：三渲二的轮廓

你看到三渲二角色最外围那圈黑色轮廓了吗？那不是贴图，不是材质，是描边（Outline）——三渲二的标志性技术。这节课讲清楚：描边是什么，怎么实现，怎么控制粗细。

核心概念

描边 Outline / Edge Detection

在物体边缘画一圈线，模拟手绘动画的轮廓线。三渲二的标志性特征——不管角色怎么动，最外围永远有一圈线。

Inverted Hull 反向壳

描边的一种实现：复制 mesh，顶点沿法线外扩，只渲染背面。正面被正常角色挡住，只露出边缘的一圈黑线。

后处理描边 Post-process Outline

另一种实现：渲染深度图或法线图，用边缘检测算法（Sobel 等）找出轮廓，叠加黑色线条。

描边的直觉

想象你有一个苹果：

1. 正常渲染：     [🍎]        ← 红苹果
2. 复制+放大：    [  🍎  ]    ← 黑苹果（比原来大一圈）
3. 只渲染背面：   [▓🍎▓]      ← 黑苹果的背面（正面被剔除了）
4. 叠加：         [▓🍎▓]      ← 红苹果盖在黑苹果上，边缘露出黑线

这就是 Inverted Hull——用几何体本身"撑出"轮廓。

两种描边方式对比

方式原理优点缺点适用
Inverted Hull复制 mesh，顶点外扩，渲染背面简单，性能好，风格化明确粗细固定，复杂模型可能穿帮三渲二角色、卡通风格
后处理渲染深度/法线图，边缘检测粗细可调，风格统一，不受模型影响复杂，性能开销大，可能检出多余边缘写实+风格化混合、特效场景
三渲二用 Inverted Hull——风格化明确，手机也能跑。后处理描边更适合"写实渲染+一点风格化"的混合风格（如《塞尔达传说：旷野之息》的远景描边）。

Inverted Hull 详解

步骤拆解

1. 复制几何体
   → 和原模型完全一样的 mesh

2. 顶点外扩（沿法线方向）
   → 每个顶点向外移动一点（比如 0.02 单位）
   → 模型"膨胀"了一圈

3. 材质设置
   → 颜色：纯黑（或你想要的描边颜色）
   → 不受光照（unshaded）
   → 只渲染背面（cull front / BackSide）

4. 渲染顺序
   → 先渲染描边（黑色背面）
   → 再渲染正常模型（盖住中间，只露边缘）

Three.js 实现

// 1. 正常角色
const character = new THREE.Mesh(geometry, toonMaterial);
scene.add(character);

// 2. 描边 mesh
const outlineGeometry = geometry.clone();
const outlineMaterial = new THREE.MeshBasicMaterial({
  color: 0x000000,           // 黑色
  side: THREE.BackSide,      // 只渲染背面
});
const outline = new THREE.Mesh(outlineGeometry, outlineMaterial);

// 3. 顶点外扩（简单版：整体放大）
outline.scale.multiplyScalar(1.02);  // 放大 2%

scene.add(outline);
注意：scale.multiplyScalar(1.02) 是"近似外扩"——简单但不够精确。精确做法是顶点着色器里沿法线外扩：vertex += normal * width。对于复杂模型，整体放大可能导致描边粗细不均（比如细长部位描边过粗）。

Godot 实现

# 方法 1：Next Pass 材质（最简单）
# 在角色的材质上添加下一层 pass
var mat = StandardMaterial3D.new()
mat.albedo_color = Color.RED
mat.next_pass = create_outline_material()

func create_outline_material():
    var outline = StandardMaterial3D.new()
    outline.albedo_color = Color.BLACK
    outline.cull_mode = BaseMaterial3D.CULL_FRONT  # 剔除正面，只渲染背面
    outline.shading_mode = BaseMaterial3D.SHADING_MODE_UNSHADED  # 不受光照
    return outline
# 方法 2：Shader（更灵活）
shader_type spatial;
render_mode cull_front, unshaded;  # 剔除正面，无光照

uniform float outline_width = 1.0;
uniform vec4 outline_color : source_color = vec4(0,0,0,1);

void vertex() {
    // 顶点沿法线外扩
    VERTEX += NORMAL * outline_width * 0.01;
}

void fragment() {
    ALBEDO = outline_color.rgb;
}

描边粗细控制

固定粗细（简单）

// 整体放大固定比例
outline.scale.multiplyScalar(1.02);  // 2% 粗细

// 问题：近大远小，远处描边细，近处描边粗
// 适合：固定视角、风格化明确的游戏

屏幕空间等宽（真实）

// Godot Shader：根据相机距离调整外扩
void vertex() {
    vec4 clip_position = PROJECTION_MATRIX * MODELVIEW_MATRIX * vec4(VERTEX, 1.0);
    vec3 clip_normal = mat3(PROJECTION_MATRIX) * mat3(MODELVIEW_MATRIX) * NORMAL;
    
    // 法线转换到屏幕空间，外扩固定像素
    vec2 offset = normalize(clip_normal.xy) / VIEWPORT_SIZE 
                  * outline_width * clip_position.w * 2.0;
    clip_position.xy += offset;
    
    POSITION = clip_position;
}
等宽描边：不管相机远近，描边在屏幕上都是固定像素宽（比如 2px）。这是动画渲染的标准做法——角色拉近时描边不会变粗，保持画面统一。

常见问题

问题原因解决
描边太粗/太细外扩比例不对调整 scale 或 outline_width
细长部位描边过粗整体放大导致比例失调用顶点着色器沿法线外扩，而不是整体 scale
描边有锯齿分辨率不足或 MSAA 未开开抗锯齿，或提高渲染分辨率
透明物体描边错乱深度排序问题描边 pass 放在透明 pass 之前

口头描述练习

🗣️ 给角色加三渲二描边，怎么描述？

"用 Inverted Hull 实现描边。复制角色 mesh，顶点沿法线外扩 2%，材质设为纯黑、不受光照、cull front（只渲染背面）。描边 pass 在正常渲染之前，这样正常模型盖住中间，只露出边缘的黑色轮廓。描边粗细用屏幕空间等宽——根据相机距离调整外扩量，保证远近都是 2px 宽。角色动画时描边跟着动，不需要额外处理。"

→ 你用了 Inverted Hull、顶点外扩、cull front、屏幕空间等宽。这就是专业级的描边描述。
