005光照：让场景活起来

上一课走廊 demo 里，你已经看到了光照的威力——灯条照亮走廊、金属地板反射光线、雾效营造纵深。这节课系统讲讲：3D 场景里有哪些光？怎么用？

四种基本光源

🌍
环境光 Ambient
均匀照亮一切，没有方向、没有阴影。像阴天的自然光——到处都有，但很平。
类比：阴天 / 室内开灯后的整体亮度
☀️
平行光 Directional
从一个方向打来的平行光线，像太阳光。有方向、有阴影，是最常用的主光源。
类比：太阳 / 远处的探照灯
💡
点光源 Point
从一个点向四面八方发光，有衰减（越远越暗）。像灯泡、蜡烛。
类比：灯泡 / 蜡烛 / 火把
🔦
聚光灯 Spot
从一个点发出锥形光束，可以控制角度和衰减。像手电筒、舞台灯。
类比：手电筒 / 舞台追光灯

你已经用过的光照

走廊 demo 里的光照方案：

// 环境光 — 整体亮度，避免完全黑暗的区域
scene.add(new THREE.AmbientLight(0x334466, 0.8));

// 点光源 — 每段走廊一个，模拟灯条照明
const light = new THREE.PointLight(0x88ccff, 3, 6, 1.5);
//                              颜色        强度 距离 衰减
light.position.set(0, H - 0.2, z);
scene.add(light);

// 平行光 — 从走廊尽头打来，增加方向感
const dirLight = new THREE.DirectionalLight(0x88aaff, 1.0);
dirLight.position.set(0, 3, -10);
scene.add(dirLight);

光照三件套：一个经典配方

摄影和 3D 渲染中的经典布光方式——三点照明：

灯位作用类比
主光 (Key Light)最强光源，决定主要明暗和阴影方向窗户进来的阳光
补光 (Fill Light)较弱的反向光，柔化阴影，避免死黑白色墙壁的反光
轮廓光 (Rim Light)从后面打，勾勒物体边缘逆光时头发边缘的亮线
// 三点照明（Three.js）
// 主光：右上方，最强
const key = new THREE.DirectionalLight(0xffffff, 2.0);
key.position.set(5, 8, 3);

// 补光：左前方，较弱，色温偏暖
const fill = new THREE.DirectionalLight(0xffddaa, 0.8);
fill.position.set(-4, 3, 5);

// 轮廓光：从后方，勾勒边缘
const rim = new THREE.DirectionalLight(0x88aaff, 1.2);
rim.position.set(0, 2, -5);
地球 demo 里就用了这个：主光 DirectionalLight(2.0) + 补光 DirectionalLight(0.8) + 环境光 AmbientLight(1.5)。没有补光，地球背面会死黑一片。

阴影

阴影让场景有深度感和真实感。Three.js 和 Godot 都支持实时阴影，但需要手动开启：

// Three.js — 开启阴影
renderer.shadowMap.enabled = true;
renderer.shadowMap.type = THREE.PCFSoftShadowMap; // 柔和阴影

light.castShadow = true;    // 光源投射阴影
mesh.castShadow = true;     // 物体产生阴影
mesh.receiveShadow = true;  // 物体接收阴影
性能注意：阴影是昂贵的。手机上建议只给主光源开阴影，或者干脆用烘焙光照（预计算阴影到贴图里）。Godot 里叫 LightmapGI。

光照衰减

点光源和聚光灯的光线会随距离衰减——越远越暗。这是真实世界的物理规律（平方反比定律）：

距离亮度（平方反比）视觉效果
1 米100%最亮
2 米25%明显变暗
4 米6%很暗
8 米1.5%几乎看不到
// Three.js — 点光源衰减参数
new THREE.PointLight(color, intensity, distance, decay);
//                                   强度        照射范围  衰减率
// distance: 光照最大距离（0 = 无限）
// decay: 衰减指数（物理正确值 = 2）

色温

光的颜色影响场景氛围：

色温颜色氛围用途
暖色 (2000-3000K)橙黄温馨、舒适室内、壁炉、夕阳
中性 (4000-5000K)白色自然、清晰办公室、白天
冷色 (6000-10000K)蓝白科技、冷峻太空站、医院、夜景

走廊 demo 用蓝白色 (0x88ccff) 就是为了科幻感。换成暖橙色 (0xff8844)，氛围立刻变成温馨的室内走廊。

口头描述练习

🗣️ 做一个恐怖游戏的地下墓穴场景，光照怎么设计？

"环境光非常暗（AmbientLight 强度 0.1，深蓝色调），让大部分区域处于昏暗中。玩家手持一个点光源（OmniLight3D），暖黄色，衰减范围 5 米——只能照亮周围一小圈。走廊尽头有一个闪烁的红色点光源，亮度随机变化，营造不安感。墙上每隔一段有一个熄灭的火把位置（不发光），偶尔有一个亮的（OmniLight3D 暖橙色，带闪烁）。不开阴影贴图——手机性能不够，用黑暗本身代替阴影营造恐怖感。"

→ 你用光源类型、颜色、强度、衰减描述了完整的光照方案。"用黑暗代替阴影"说明你已经理解了光照和性能的关系。
