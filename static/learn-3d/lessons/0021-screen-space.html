021屏幕空间效果：用屏幕信息造假

墙角比墙中间暗一点、水面反射天空、地面积水倒映霓虹灯——这些效果的真实模拟都太贵。但有个取巧的思路：只利用"屏幕上已经画出来的信息"去近似，这就是屏幕空间（Screen Space）系列技术。

核心思想

屏幕空间 Screen Space

不重新渲染场景，只用当前帧的图像（颜色/深度/法线）做后处理。优势：一次 pass 全屏生效，性能可控。局限：屏幕外的信息看不到——水面反射不了背后的物体，AO 不知道墙后面是什么。

SSAO：屏幕空间环境光遮蔽

第 7 课学过 AO 贴图——美术离线烘焙好的遮蔽。SSAO 是实时版：用屏幕深度+法线信息，估算每个像素"被周围几何遮挡的程度"。

// SSAO 原理（简化）
// 对每个像素，从相机出发看它周围的半球
// 采样若干点，查深度图：这些点被挡住的比例 = 遮蔽值
float ssao(vec2 uv) {
  float occlusion = 0;
  for (int i = 0; i < samples; i++) {
    vec3 samplePos = 像素位置 + 半球随机方向[i] * radius;
    float depth = texture(depthMap, 投影到屏幕(samplePos)).r;
    if (samplePos.z > depth) occlusion += 1.0;  // 被挡住
  }
  return 1.0 - occlusion / samples;  // 1=无遮蔽，0=全遮蔽
}
变体特点性能
SSAO经典版，Crytek 2007 首创中
HBAONVIDIA 改进版，更准，考虑法线方向中高
GTAOIntel 版，基于地平线角度，质量最高高
SSAO+（半分辨率）降采样+上采样，手机常用低
AO 是"假得很有用"：真实的间接光照太贵，AO 用"遮蔽程度"近似——墙角、缝隙、褶皱自然变暗，画面立刻有了立体感和层次。这就是为什么 2010 年后的游戏几乎都有 SSAO。

SSR：屏幕空间反射

湿地面倒映霓虹、水面反射天空、大理石地面映出柱子——SSR 用屏幕上的图像做反射：

// SSR 原理
// 从像素位置沿反射方向在屏幕空间步进
// 找到与几何体的交点，取那一点的颜色作为反射色
vec3 ssr(vec2 uv, vec3 normal, vec3 viewDir) {
  vec3 reflectDir = reflect(-viewDir, normal);
  for (float t = 0; t < maxDist; t += step) {
    vec3 p = 像素位置 + reflectDir * t;
    vec2 screenUV = 投影到屏幕(p);
    float depth = texture(depthMap, screenUV).r;
    if (p.z < depth) {  // 击中几何
      return texture(colorMap, screenUV).rgb;
    }
  }
  return 天空色;  // 没击中，反射天空
}
优点局限
实时反射，不用预烘焙屏幕外的物体反射不了——相机背后的物体消失
一次 pass 全屏生效边缘截断——反射到屏幕边缘就断了
适合平面（地面/水面/镜子）凹凸表面反射会扭曲
SSR 的经典穿帮：角色站在水边，水里反射出角色的腿——但角色上半身超出屏幕顶部，水里的倒影到腰部就断了。解决：SSR + 立方体贴图反射探针兜底，或只用 SSR 做近景反射。

屏幕空间折射

水面、玻璃、热浪扭曲——折射让光线穿过透明物体时偏折：

// 折射原理：法线扰动 UV
vec2 refractUV = uv + normal.xy * strength;
vec3 color = texture(sceneColor, refractUV).rgb;
// 屏幕图像被法线"扭"了一下，看起来光线弯了

这就是水面 shader 的核心——不需要真模拟光路，只需要"扭 UV"就能做出波光粼粼。

屏幕空间阴影

阴影贴图管不到的细节（自阴影、细小物体阴影），屏幕空间补：

// 屏幕空间阴影：沿光线方向在屏幕空间步进
// 查深度图，看这条视线上有没有遮挡
float screenSpaceShadow(vec2 uv, vec3 lightDir) {
  for (float t = 0; t < maxDist; t += step) {
    vec3 p = 像素位置 + lightDir * t;
    float depth = texture(depthMap, 投影到屏幕(p)).r;
    if (p.z > depth) return 0.3;  // 在阴影里
  }
  return 1.0;  // 被照亮
}

三大屏幕空间效果对比

SSAOSSR折射
效果角落缝隙变暗水面地面反射光线弯曲（水/玻璃）
输入深度+法线深度+颜色+法线颜色+法线
原理半球采样查遮挡反射方向步进法线扰动 UV
性能中中高低
手机半分辨率可用谨慎（只给水面）便宜，常用
穿帮远处浮起、边缘光晕屏幕外物体消失扭曲不真实

为什么"屏幕空间"是性价比之王

对比屏幕空间物理精确
AOSSAO 实时算光线追踪 GI（贵几个数量级）
反射SSR 步进查深度光线追踪反射 / 平面反射（再渲染一遍）
折射UV 扰动真实光路模拟
成本一次后处理 pass重新渲染整个场景
屏幕空间的哲学：80% 效果，20% 成本。穿帮？玩家不细看就不会注意。这就是为什么从 Crysis 到原神，屏幕空间技术是实时渲染的支柱。

Three.js 实现

import { SSAOPass } from 'three/addons/postprocessing/SSAOPass.js';
import { SSRPass } from 'three/addons/postprocessing/SSRPass.js';

// SSAO
const ssaoPass = new SSAOPass(scene, camera, width, height);
ssaoPass.kernelRadius = 8;
composer.addPass(ssaoPass);

// SSR（水面/地面）
const ssrPass = new SSRPass({ renderer, scene, camera, width, height });
ssrPass.opacity = 0.5;
composer.addPass(ssrPass);

Godot 实现

# Godot 4：WorldEnvironment 节点
extends WorldEnvironment

func _ready():
    var env = Environment.new()
    
    # SSAO
    env.ssao_enabled = true
    env.ssao_radius = 1.0
    env.ssao_intensity = 2.0
    
    # SSR
    env.ssr_enabled = true
    env.ssr_max_steps = 64
    env.ssr_fade_in = 0.15
    env.ssr_fade_out = 2.0

🗣️ 手机 RPG 的屏幕空间方案怎么描述？

"SSAO 开半分辨率，半径 1 米，强度中等——给墙角、树根、石头缝隙加层次感，性能开销可控。SSR 只给水面——角色场景的水面反射用 SSR，但限制反射距离 20 米，超出部分用天空盒反射探针兜底，避免屏幕边缘截断穿帮。折射用在角色技能特效——水面波纹、热浪扭曲用法线扰动 UV，便宜且效果华丽。阴影用屏幕空间补自阴影——角色头发、衣服褶皱的细节阴影，主阴影贴图分辨率不够的部分。屏幕空间是手机平台的主力——物理精确的 GI 和反射想都不敢想，屏幕空间给了 80% 的效果。"

→ 你用了半分辨率 SSAO、SSR 距离限制+兜底、折射特效应用、屏幕空间阴影补充、性能权衡。这就是手机平台的屏幕空间方案。
