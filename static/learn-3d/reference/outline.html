🖊️ 描边速查卡

两种方式

方式原理适用
Inverted Hull复制 mesh，顶点外扩，渲染背面三渲二角色、卡通风格
后处理深度/法线图 + 边缘检测写实+风格化混合

Inverted Hull 步骤

1. 复制几何体
2. 顶点外扩（沿法线）
3. 材质：纯黑 + 不受光照 + 只渲染背面
4. 先渲染描边，再渲染正常模型

关键参数

参数作用推荐值
outline_width描边粗细0.01 ~ 0.03（模型单位）
scale简单外扩比例1.01 ~ 1.05
cull_mode面剔除Front（只渲染背面）
shading_mode光照Unshaded（不受光照）

Three.js 代码

// 描边材质
const outlineMat = new THREE.MeshBasicMaterial({
  color: 0x000000,
  side: THREE.BackSide,  // 只渲染背面
});

// 描边 mesh（整体放大近似）
const outline = new THREE.Mesh(geometry.clone(), outlineMat);
outline.scale.multiplyScalar(1.02);
scene.add(outline);

Godot 代码

# Next Pass 材质
outline.albedo_color = Color.BLACK
outline.cull_mode = BaseMaterial3D.CULL_FRONT

常见问题

问题解决
描边粗细不均用顶点着色器沿法线外扩，不要整体 scale
远处描边太细屏幕空间等宽（根据相机距离调整）
透明物体描边错乱描边 pass 放在透明 pass 之前
