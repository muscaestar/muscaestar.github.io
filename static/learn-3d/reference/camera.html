相机类型

类型特点用途
透视 Perspective近大远小，有深度感大部分 3D 游戏
正交 Orthographic远近一样大，无透视2.5D、等轴测、UI

FOV 参考

FOV效果场景
20-35°望远镜，压缩空间狙击镜、特写
45-60°接近人眼，自然RPG、探索
70-90°宽视野，速度感FPS、竞速
100°+鱼眼变形VR、特效

常用参数

// Three.js
new THREE.PerspectiveCamera(fov, aspect, near, far)
// 推荐: fov=50, near=0.1, far=场景大小
// far/near 比值 < 10000（防 z-fighting）

// Godot
Camera3D.fov = 50.0
Camera3D.near = 0.1
Camera3D.far = 500.0

视角模式

模式FOV相机位置
第一人称70-90°角色头部 (y+1.6)
第三人称50-60°角色后上方 (y+2, z-4)
俯视/RTS30-45°高空向下

常见问题

问题原因解决
近处物体消失near 太大near 改 0.1
远处物体消失far 太小增大 far
面闪烁 z-fightingfar/near 比值太大增大 near 或减小 far
画面变形FOV 太大FOV 降到 60-90°
