UV 坐标

(0,0) = 纹理左下角
(1,1) = 纹理右上角
范围: 0.0 ~ 1.0（归一化）

超出 0~1 时由包裹模式决定：
  RepeatWrapping  → 平铺重复
  ClampToEdge     → 边缘拉伸
  MirroredRepeat  → 镜像平铺

法线贴图原理

RGB = 法线 XYZ 方向
R = X（左右）  G = Y（上下）  B = Z（朝向）
平坦表面 (0,0,1) → RGB(0.5,0.5,1.0) = 蓝紫色
