三种动画方式

方式适用性能
关键帧简单机械运动便宜
补间 (Tween)UI、镜头、简单物体便宜
骨骼动画角色、生物中等（骨骼数量决定）

缓动曲线

曲线感觉适用
Linear匀速机械运动
Ease In先慢后快物体启动
Ease Out先快后慢UI 弹入
Ease InOut两头慢相机移动
Bounce弹跳掉落、按钮
Elastic橡皮筋弹性 UI

动画状态机

状态切换 + 动画混合（Crossfade）
  
  idle ←→ walk ←→ run
    ↑       ↑
    ↓       ↓
   jump   attack

过渡时间：0.2s（避免硬切）

骨骼动画核心

顶点权重：
  膝盖顶点 = 大腿骨 50% + 小腿骨 50%
  
  → 弯曲时平滑变形，不撕裂
