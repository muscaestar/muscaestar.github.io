🎨 色阶速查卡

核心公式

// 色阶离散化
float cel = floor(intensity * levels) / levels;

// 3 级色阶结果：
// intensity 0.0~0.33 → cel = 0.0
// intensity 0.33~0.66 → cel ≈ 0.33
// intensity 0.66~1.0 → cel ≈ 0.66
// intensity = 1.0 → cel = 1.0

级数选择

级数风格适用
2 级极简海报Logo、图标
3 级经典动漫大多数三渲二
4 级细腻动漫角色特写
5 级半写实风格化但保留细节

过渡硬度

类型公式风格
硬切floor(x * n) / n经典赛璐璐
软过渡mix + smoothstep现代动漫

阴影色选择

颜色氛围例子
纯黑经典强烈老式漫画
深蓝/紫夜晚神秘《幽灵公主》
深棕/暖色黄昏温暖《千与千寻》
互补色艺术风格化《蜘蛛侠：平行宇宙》

Godot 快速设置

# StandardMaterial3D
shading_mode = SHADING_MODE_CEL
cel_levels = 3
cel_threshold = 0.5

# 或 Shader
render_mode diffuse_toon, specular_toon;

Three.js 核心代码

float intensity = max(dot(normal, lightDir), 0.0);
float cel = floor(intensity * levels) / levels;
vec3 color = mix(shadowColor, albedo, cel);
