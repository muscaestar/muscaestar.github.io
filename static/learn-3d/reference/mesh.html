核心公式

Mesh = Geometry（形状）+ Material（外观）

基本组成

术语说明
Vertex顶点，3D 空间中的一个点 (x,y,z)
Triangle / Face3 个顶点连成的面，GPU 渲染的基本单位
Normal法线，顶点/面的朝向，决定光照效果
Segments分段数，控制几何体精度和圆滑度

内置几何体

Three.jsGodot形状用途
SphereGeometrySphereMesh球体星球、球
BoxGeometryBoxMesh立方体建筑、方块
CylinderGeometryCylinderMesh圆柱柱子、树干
ConeGeometryConeMesh（用 CylinderMesh 顶半径=0）圆锥屋顶、山
TorusGeometryTorusMesh圆环甜甜圈、戒指
PlaneGeometryPlaneMesh平面地面、墙

分段数与精度

分段顶点数效果场景
8~100低多边形远景、风格化
32~2000较圆滑一般场景
64~8000很圆滑近景特写
