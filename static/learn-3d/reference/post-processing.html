原理

场景 → Render Target 纹理
     → pass 1（Bloom）
     → pass 2（色调映射）
     → pass 3（暗角）
     → 屏幕

每个 pass = 一次全屏 shader

效果清单

效果作用成本手机
Bloom亮部光晕中✅ 低分辨率做
色调映射HDR→LDR极低✅ 必用
暗角四角变暗极低✅ 随便用
色差RGB 错位低✅ 可用
颜色分级LUT 调色低✅ 可用
SSAO缝隙变暗高⚠️ 用烘焙 AO 替代
景深焦点外模糊高⚠️ 只过场用
运动模糊拖影中高❌ 一般不用

Bloom 三参数

参数作用调大效果
threshold多亮才发光更少东西发光
strength光晕强度光更亮更溢
radius光晕扩散范围光晕更大更糊

色调映射曲线

曲线特点场景
ACES电影工业标准，色彩好默认选择
Reinhard简单，亮部压缩狠简单场景
AgX新版，暗部更好Blender 默认

Three.js

const composer = new EffectComposer(renderer);
composer.addPass(new RenderPass(scene, camera));
composer.addPass(new UnrealBloomPass(res, 0.5, 0.4, 0.85));
composer.render();  // 替代 renderer.render()

renderer.toneMapping = THREE.ACESFilmicToneMapping;
