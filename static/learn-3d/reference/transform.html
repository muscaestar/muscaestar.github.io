三大属性

属性作用示例
position位置 (x, y, z)(0, 1.5, -3)
rotation旋转（弧度）(0, π/4, 0)
scale缩放倍数(2, 2, 2)

坐标系（右手）

轴方向常见用途
X→ 右左右移动
Y↑ 上高度、跳跃
Z⊙ 朝观察者前后移动

弧度 ↔ 角度

90°  = π/2   ≈ 1.5708
180° = π     ≈ 3.1416
270° = 3π/2  ≈ 4.7124
360° = 2π    ≈ 6.2832

// Three.js
THREE.MathUtils.degToRad(90)  // → 1.5708
THREE.MathUtils.radToDeg(1.5708) // → 90

// Godot
deg_to_rad(90)   // → 1.5708
rad_to_deg(1.5708) // → 90

局部 vs 世界

// Three.js
obj.position          // 局部坐标（相对父节点）
obj.getWorldPosition(v) // 世界坐标（写入 v）

// Godot
obj.position           // 局部坐标
obj.global_position    // 世界坐标

Three.js ↔ Godot 对照

Three.jsGodot
obj.position.set(x,y,z)obj.position = Vector3(x,y,z)

obj.lookAt(target)obj.look_at(target)
