S6天花板报告：无 shader 能做到什么

6 课做完了。这门课的命题是"不用 shader，风格化能走多远"——现在你有了一份亲手验证过的答案。这份报告不是背出来的，是你在 S1~S5 里一次次踩坑、一次次确认边界后攒下的。它是你以后决定"要不要学 shader"的依据。

规律很清晰：越是"整体氛围/渲染参数"层面的风格（调色、像素化），无 shader 越能打；越是"逐像素/逐通道精细操作"的效果（RGB 错位、动态网点），越撞天花板。

逐课报告卡

S1 三渲二 70 分

✅ 做到：Inverted Hull 描边（复制 mesh+背面+外扩）、预烘焙色阶贴图（静态二分）、冷色阴影染色、主角选择性描边。

🚧 卡住：动态色阶（光照变化时色阶边界实时移动）——预烘焙贴图是死的，灯光一转色阶不跟。还有空心/薄片 mesh 描边（石圈/草/旗）——Inverted Hull 背面翻出变黑。

S2 氛围调色 90 分

✅ 做到：5 种调性（正午/黄昏/夜晚/雾林/异变）全靠光照颜色+雾+toneMappingExposure+CSS 暗角。同一个营地 5 个世界。

🚧 卡住：局部调色（只调角色不调背景、只调暗部色相）——CSS 和光照都是全局的，局部调色要 LUT shader。

S3 漫画/网点 65 分

✅ 做到：高对比光照（拉阳光压环境光）、CSS 半调网点（multiply）、Canvas 放射线速度线（疾跑/爆发触发）、漫画描边。

🚧 卡住：网点随光照/距离变化（亮部无点、暗部密点、近大远小）——CSS 网点是静态平铺，不感知场景光照。真·随视角速度线也要 shader。

S4 像素/复古 90 分

✅ 做到：低分辨率渲染+最近邻放大（像素感本质）、CSS 降色近似调色板、噪点抖动、CRT 扫描线、4 档复古预设（HD/GBA/红白机/GameBoy）。

🚧 卡住：逐像素调色板量化（真 16 色调色板、有序抖动 dithering）——CSS filter 只能近似降色，真调色板要逐像素 shader。

S5 故障/科幻 55 分

✅ 做到：CSS 扫描故障条（随机跳动+扭曲）、canvas transform 画面抖动、CSS 数字噪点、信号干扰爆发。

🚧 卡住：RGB 通道错位——drop-shadow 认 canvas alpha 被背景盖住，SVG filter 在 iSH WebKit 的 WebGL canvas 上不可靠。这是本课唯一彻底失败的技术。

无 shader 天花板清单

这 4 项是你亲手验证"做不到"的——它们就是 shader 存在的理由：

1. RGB 通道错位 / 色差（Chromatic Aberration）
需要逐通道采样偏移——CSS drop-shadow 认元素 alpha 被背景盖住，SVG filter 在 WebGL canvas 上不可靠。
→ shader 解法：后处理 pass 里对 R/G/B 三通道分别做 UV 偏移采样，几行 GLSL。
2. 动态色阶（随光照实时的 Cel Shading）
预烘焙渐变贴图是静态的——灯光方向一变，色阶边界不跟着动，卡通感穿帮。
→ shader 解法：自定义光照模型，fragment 里 floor(NdotL × levels)/levels 实时离散。
3. 屏幕空间边缘检测描边（空心/薄片也能描）
Inverted Hull 只适用实心封闭 mesh——空心环形/薄片背面翻出。石圈/草/旗描边只能换方案。
→ shader 解法：Sobel 边缘检测后处理，对深度/法线突变处描边，与几何结构无关。
4. 随场景变化的网点/速度线（感知光照和距离）
CSS 网点/速度线是静态平铺/固定面片——不感知场景光照强弱、不感知物体远近。
→ shader 解法：网点 shader 读 NdotL 决定点密度，速度线 shader 读屏幕空间速度矢量。

shader 进阶地图

如果你决定继续深入，shader 学习的路径已经很清晰——就从这 4 个"卡住点"入手，每一个都是小而具体的入门项目：

入门项目shader 概念难度对应卡住点
RGB 错位后处理后处理 pass + UV 偏移⭐ 最简单S5 RGB 错位
自定义色阶光照fragment shader + NdotL⭐⭐S1 动态色阶
Sobel 边缘检测描边深度/法线缓冲 + 卷积⭐⭐⭐S1 空心描边
光照感知网点光照数据 + 程序化纹理⭐⭐⭐⭐S3 动态网点
推荐从 RGB 错位后处理入手——它是"hello world"级的 shader：一个全屏 quad、一个 fragment shader、三通道 UV 偏移。你能用它在 S5 的场景上做出真正的色差故障，成就感拉满，而且立刻理解"后处理 pass"这个现代渲染的核心概念。

核心结论

无 shader 能走多远？

答案：整体氛围和渲染参数层面能走很远（70~90 分），逐像素精细操作就走不动了（55 分以下）。调色、像素化、描边、网点、速度线、故障条、抖动——这些"风格化"的主力军引擎都自带。shader 补的是最后 20% 的精细控制：通道操作、动态响应、屏幕空间效果。

你现在的判断力

以后再看到任何风格化效果，你能立刻判断："这是引擎能做的（调参数/后处理/贴图），还是必须 shader（通道/动态/屏幕空间）"。这个判断力比会写 shader 更值钱——它让你在项目里正确估算成本、正确选型。
