📖 场景图速查卡

核心术语

Three.jsGodot说明
SceneSceneTree3D 世界容器
Object3DNode3D场景图中的节点
GroupNode3D纯组织用空节点
MeshMeshInstance3D可见的 3D 物体
.add(child).add_child(node)添加子节点
.remove(child).remove_child(node)移除子节点
.parent.get_parent()获取父节点
.children.get_children()获取子节点列表

关键规则

子节点继承父节点的变换（位置、旋转、缩放）。父节点动 → 子孙全动。

最终位置 = 所有祖先变换的叠加。从根节点到当前节点，每一层的位置/旋转/缩放都会乘在一起。

常见模式

// 太阳系模型
sunGroup (自转 → 行星公转)
├── earthGroup (自转 → 月球公转)
│   ├── earth (Mesh)
│   └── moon (Mesh)
└── marsGroup (自转)
    └── mars (Mesh)

// 角色手持武器
character (Node3D)
├── body (Mesh)
├── hand (Node3D) ← 挂点
│   └── sword (Mesh) ← 跟随手移动
└── camera (Node3D) ← 跟随角色视角

常用操作

// Three.js
const group = new THREE.Group();
scene.add(group);
group.add(mesh1, mesh2);
mesh1.position.set(1, 0, 0); // 相对于 group 的局部坐标

// Godot (GDScript)
var group = Node3D.new()
add_child(group)
group.add_child(mesh1)
mesh1.position = Vector3(1, 0, 0) # 局部坐标
