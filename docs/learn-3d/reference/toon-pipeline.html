🎨 三渲二速查卡

完整配方

1
描边：Inverted Hull，2% 粗细，黑色背面
2
色阶：3 级硬切，阴影色 #2a2a4a
3
材质简化：平涂色，去 PBR 细节
4
阴影：硬边（可选）

Three.js 快速实现

// 1. 材质：MeshToonMaterial（内置色阶）
const mat = new THREE.MeshToonMaterial({ color: 0xff6b6b });

// 2. 描边：Inverted Hull
const outline = new THREE.Mesh(
  geometry.clone(),
  new THREE.MeshBasicMaterial({ 
    color: 0x000000, 
    side: THREE.BackSide 
  })
);
outline.scale.multiplyScalar(1.02);

Godot 快速实现

# 材质：StandardMaterial3D + Cel
mat.shading_mode = SHADING_MODE_CEL
mat.cel_levels = 3

# 描边：Next Pass
outline.cull_mode = CULL_FRONT
outline.shading_mode = SHADING_MODE_UNSHADED
mat.next_pass = outline

常见问题

问题解决
描边太粗/细调 scale（1.01~1.05）或 outline_width
色阶过渡不自然调 cel_threshold 或换软过渡
阴影太黑阴影色改深蓝/深棕，不用纯黑
和写实场景不搭场景也做简化，或加统一后处理
