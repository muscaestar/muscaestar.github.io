003网格：3D 物体的形状

前两课讲了场景怎么组织、物体怎么摆放。这节课讲物体本身——它们的形状是怎么定义的？

核心概念

网格 Mesh

3D 世界中可见物体的基本单元。Mesh = 形状（Geometry）+ 外观（Material）。你在地球 demo 里写的 new THREE.Mesh(geometry, material) 就是在创建网格。

几何体 Geometry

定义物体的形状——顶点在哪、面怎么连。球体、立方体、圆柱体都是几何体。Geometry 只关心形状，不关心颜色。

顶点 Vertex（复数 Vertices）

3D 空间中的一个点 (x, y, z)。几何体由大量顶点组成。一个立方体有 8 个顶点，一个高精度球体可能有几千个。

三角形 Triangle / Face

连接 3 个顶点形成的面。所有 3D 物体最终都是三角形组成的——这是 GPU 渲染的基本单位。一个立方体 = 12 个三角形（每个面 2 个）。

法线 Normal

顶点或面的朝向——一个垂直于表面的向量。法线告诉光照"这个面朝哪"，决定了明暗效果。法线错误 = 光照看起来不对。

内置几何体

Three.js 和 Godot 都提供常用几何体，不需要手动画三角形：

// Three.js
const geo = new THREE.SphereGeometry(1, 32, 32);  // 半径1, 32段
const mesh = new THREE.Mesh(geo, material);
scene.add(mesh);

// Godot — 用 MeshInstance3D + 内置 mesh 资源
var mesh_instance = MeshInstance3D.new()
mesh_instance.mesh = SphereMesh.new()  // 或 BoxMesh, CylinderMesh...
add_child(mesh_instance)

细节等级 Segments / Subdivisions

几何体的"精度"由分段数决定：

// 同一个球体，不同精度
new THREE.SphereGeometry(1, 8, 8)    // 低精度 — 像多面体
new THREE.SphereGeometry(1, 32, 32)  // 中等 — 比较圆滑
new THREE.SphereGeometry(1, 64, 64)  // 高精度 — 很圆滑，但顶点多
分段数顶点数效果适用场景
8×8~100明显棱角远景、低多边形风格
32×32~2000较圆滑一般场景
64×64~8000很圆滑近景特写
性能原则：顶点越多，渲染越慢。手机上建议控制在 32 段以内。远景物体用低精度，近景才需要高精度。这在 Godot 里叫 LOD（Level of Detail，细节等级）。

从文件加载模型

内置几何体够用做原型，但真正的游戏角色、场景需要从 3D 建模软件（Blender、Maya）导出模型文件加载：

格式说明Three.jsGodot
GLTF/GLB现代标准，推荐GLTFLoader原生支持
OBJ老格式，简单OBJLoader原生支持
FBXAutodesk 格式FBXLoader需转换
// Three.js — 加载 GLTF 模型
import { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js';
const loader = new GLTFLoader();
loader.load('model.glb', (gltf) => {
  scene.add(gltf.scene);  // gltf.scene 是一个 Group
});

// Godot — 直接拖 .glb 文件到场景树，引擎自动导入
Godot 对照：Godot 的 MeshInstance3D = Three.js 的 Mesh。Godot 的 mesh 资源（SphereMesh、BoxMesh 或导入的 .glb）= Three.js 的 Geometry。

口头描述练习

🗣️ 做一个低多边形风格的森林场景，怎么描述？

"地面用一个大的 PlaneGeometry 作为草地。树用两种几何体组合：CylinderGeometry 做树干，ConeGeometry 做树冠——每个都是 MeshInstance3D，共用一个低分段数（8段），呈现低多边形风格。场景里散布 20-30 棵树，用不同的 scale 让它们大小不一。加几个 SphereGeometry(1, 6, 6) 做石头——6 段让它看起来像多面体而不是光滑的球。"

→ 你用几何体类型、分段数、组合方式描述了一个完整场景。低分段 = 低多边形风格，这是 3D 美术的重要概念。
