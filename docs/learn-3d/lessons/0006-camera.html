006相机：观察世界的眼睛

你已经做了很多 demo——地球、走廊、篝火。每个都用了相机，但你有没有注意到：篝火 demo 的相机 FOV 是 50，走廊是 60，地球是 45？这节课讲清楚相机到底在干什么。

核心概念

透视相机 PerspectiveCamera

模拟人眼——近的物体大，远的物体小。绝大多数 3D 游戏和场景都用这个。Three.js 和 Godot 的默认相机都是透视相机。

正交相机 OrthographicCamera

没有透视效果——不管远近，物体大小不变。像 CAD 软件、2.5D 游戏（SimCity、纪念碑谷）用的那种"等轴测"视角。

视场角 FOV (Field of View)

相机能看到的范围，用角度表示。FOV 小 = 望远镜（放大远景），FOV 大 = 广角镜头（视野宽但边缘变形）。

视锥 Frustum

相机能看到的 3D 空间范围——一个截顶的金字塔形。只有视锥内的物体才会被渲染。由近裁剪面（near）和远裁剪面（far）定义。

透视 vs 正交

🔭
透视相机

// Three.js — 透视相机（最常用）
const camera = new THREE.PerspectiveCamera(
  50,                          // FOV（视场角，度）
  innerWidth / innerHeight,    // 宽高比
  0.1,                         // 近裁剪面
  1000                         // 远裁剪面
);

// Three.js — 正交相机
const frustumSize = 10;
const aspect = innerWidth / innerHeight;
const camera = new THREE.OrthographicCamera(
  -frustumSize * aspect / 2,  // 左
   frustumSize * aspect / 2,  // 右
   frustumSize / 2,           // 上
  -frustumSize / 2,           // 下
  0.1, 1000                   // 近/远裁剪面
);

近裁剪面和远裁剪面

new THREE.PerspectiveCamera(50, aspect, 0.1, 1000);
//                                       ↑      ↑
//                                     near    far

相机只渲染 near 到 far 之间的物体：

  • near 太大：近处物体被裁掉（穿模时看不见）
  • far 太小：远处物体消失（山体、天空盒不见了）
  • far / near 比值太大：深度精度不够，出现 z-fighting（两个面闪烁）
经验值：near = 0.1，far 根据场景大小设（室内 50，户外 500-2000）。far/near 比值控制在 10000 以内。

👁️
第一人称
相机就是玩家的眼睛，FOV 通常 70-90°
FPS、VR、恐怖游戏
🎥
第三人称
相机跟随角色背后，FOV 通常 50-60°
RPG、动作冒险、平台跳跃
// 第一人称 — 相机绑在角色头上
camera.position = player.position + Vector3(0, 1.7, 0)

// 第三人称 — 相机在角色后方偏移
camera.position = player.position
  + Vector3(0, 2, -4)    // 后上方偏移
camera.look_at(player.position)

你已经用过的相机控制

OrbitControls 是最常用的相机控制器——拖拽旋转、滚轮缩放、自动环绕：

// Three.js
const controls = new OrbitControls(camera, renderer.domElement);
controls.enableDamping = true;      // 阻尼（惯性）
controls.dampingFactor = 0.06;
controls.minDistance = 1.5;         // 最近距离
controls.maxDistance = 10;          // 最远距离
controls.enablePan = false;         // 禁用平移
controls.target.set(0, 0.5, 0);    // 看向的点

篝火 demo 里你用过两种模式：静坐（自动漂移相机）和自由（OrbitControls）。静坐模式的相机就是每帧手动设置 position 和 lookAt。

口头描述练习

🗣️ 做一个恐怖游戏，主角在废弃医院里探索，相机怎么设计？

"第一人称视角，Camera3D 透视模式，FOV 70°——比标准 FPS 略窄，增加幽闭感。near=0.05，far=50——far 故意设小，远处自然被黑暗吞没。相机绑在角色头部位置（position.y + 1.6），加轻微的头部摆动（走路时 position.y 上下浮动 0.02，rotation.z 左右微倾 0.5°）。开门时相机缓慢转向（0.5 秒 lerp 到新角度），增加紧张感。不开 OrbitControls——玩家只能通过 WASD 和鼠标控制视角。"

→ 你用 FOV、near/far、相机绑定、头部摆动、lerp 过渡描述了完整的恐怖游戏相机方案。"FOV 略窄增加幽闭感"说明你已经理解了 FOV 对情绪的影响。
