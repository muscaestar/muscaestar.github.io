022风格化特效：卡通水、速度线和像素化

前面学的都是"怎么更像现实"。风格化特效反过来——故意不像现实，用夸张、简化、符号化的方式表达。三渲二描边、像素化、漫画速度线，都是"放弃物理正确，追求表现力"。

核心思想

风格化渲染 Stylized Rendering

目标不是"照片级真实"，而是"像某种艺术形式"——像手绘、像漫画、像像素游戏、像水彩。技术手段：简化光照（色阶）、夸张轮廓（描边）、符号化特效（速度线）、降低精度（像素化）。

卡通水：风格化水面

真实水面要 SSR + 折射 + 波浪模拟，风格化水面用"图案+动画"：

// 卡通水核心：色阶 + 滚动贴图 + 简单折射
// 1. 基础色：深水/浅水两档色阶
float depth = texture(depthMap, uv).r;
vec3 waterColor = mix(deepColor, shallowColor, step(depth, threshold));

// 2. 波纹：两张噪声贴图以不同速度滚动叠加
vec2 waveUV = uv + noise1(uv * 2.0 + time * 0.1).rg * 0.05
                   + noise2(uv * 4.0 - time * 0.15).rg * 0.03;
vec3 wave = texture(waveTexture, waveUV).rgb;

// 3. 边缘泡沫：深度接近 0 的地方画白色
float foam = step(depth, foamThreshold);
waterColor = mix(waterColor, vec3(1), foam * 0.8);
元素做法效果
深水/浅水深度色阶，两档颜色一眼看出深浅
波纹噪声贴图滚动流动感
边缘泡沫深度接近 0 画白色水与岸的交界
高光卡通大高光点波光粼粼
《原神》《塞尔达》的水都是这个思路：不追求物理正确，追求"一眼认出是水"+"好看"。色阶+图案+动画，比 SSR 水面便宜十倍，效果还更"卡通"。

速度线：漫画式动感

冲刺、挥拳、爆炸——漫画用速度线表达"快"，游戏也用：

// 速度线：屏幕空间后处理
// 1. 计算每个像素到屏幕中心的距离和角度
vec2 toCenter = uv - vec2(0.5);
float angle = atan(toCenter.y, toCenter.x);

// 2. 角度 × 频率 → 条纹
float lines = step(0.8, fract(angle * 20.0 + time * 5.0));

// 3. 距离中心越远越强（中心清晰，边缘模糊）
float radial = smoothstep(0.3, 0.8, length(toCenter));
fragColor.rgb += lines * radial * intensity;
变体效果场景
放射线从中心向外辐射冲刺、爆炸
平行线同一方向排列横向移动、挥拳
环形线同心圆扩散冲击波、落地

像素化：复古即风格

// 像素化：UV 取整，强制回到网格
vec2 pixelUV = floor(uv * resolution) / resolution;
vec3 color = texture(scene, pixelUV).rgb;
// resolution 越低，像素越大，越"复古"
分辨率效果参考
320×180轻度像素化，现代复古《Octopath Traveler》
160×90明显像素风《Celeste》过场
64×36极端像素化艺术效果

风格化 vs 写实的取舍

写实风格化
目标照片级真实像某种艺术形式
光照PBR 完整模型色阶简化
反射SSR / 光线追踪假反射 / 省略
阴影PCF 软阴影色阶阴影 / 贴图阴影
性能贵便宜
适合3A 写实游戏独立游戏 / 手游 / 二次元
风格化不是"做不好写实"——它是主动选择。好的风格化比写实更难：需要美术定调、技术配合、全团队统一审美。《塞尔达》的水彩风、《原神》的二次元渲染，背后都是大量风格化技术的积累。

Three.js 实现

// 像素化后处理
const pixelShader = {
  uniforms: { tDiffuse: { value: null }, resolution: { value: new THREE.Vector2(320, 180) } },
  vertexShader: `varying vec2 vUv; void main() { vUv = uv; gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1); }`,
  fragmentShader: `
    uniform sampler2D tDiffuse;
    uniform vec2 resolution;
    varying vec2 vUv;
    void main() {
      vec2 pixelUV = floor(vUv * resolution) / resolution;
      gl_FragColor = texture2D(tDiffuse, pixelUV);
    }
  `
};
const pixelPass = new ShaderPass(pixelShader);
composer.addPass(pixelPass);

🗣️ 二次元手游的风格化特效方案怎么描述？

"角色渲染：三渲二色阶+描边（前面学过的配方）。特效：技能用卡通水思路——色阶+噪声贴图滚动+边缘泡沫，不做 SSR 反射。速度线：冲刺/大招触发屏幕空间放射线，从角色位置向外辐射，配合 FOV 拉宽+相机震动。像素化：复古彩蛋模式——渲染分辨率降到 25%，上采样到全屏。CRT 效果：怀旧关卡加扫描线+边缘暗角+轻微色差。故障艺术：BOSS 战转场用 UV 随机偏移+色彩分离，营造紧张感。所有风格化特效都围绕'二次元美术调性'统一设计，不混搭写实特效。"

→ 你用了三渲二角色+卡通水特效+速度线+像素化彩蛋+CRT+故障艺术，并强调风格统一。这就是完整的二次元手游风格化方案。
