008动画：让场景动起来

前面 7 课搭好了静态场景——几何体、材质、光照、相机、纹理。但游戏不是幻灯片，东西要动起来。这节课讲动画的三种基本方式：关键帧、补间、骨骼动画。

核心概念

动画 Animation

属性随时间变化。位置、旋转、缩放、颜色、透明度——任何属性都可以动。动画系统就是"告诉 GPU：这个值在 t=0 时是 A，t=1 时是 B，中间自动算"。

关键帧 Keyframe

你在某些时间点手动设置属性值（"t=0 时位置在 (0,0,0)，t=2 时在 (5,0,0)"），中间由引擎插值。最基础的动画方式。

补间 Tween / Interpolation

两个关键帧之间的自动过渡。你只管起点和终点，中间引擎帮你算。可以控制缓动曲线（先快后慢、弹跳等）。

骨骼动画 Skeletal Animation

给模型绑一套"骨骼"，移动骨骼带动皮肤变形。角色走路、挥手、表情都是骨骼动画。游戏角色动画的标准做法。

三种动画方式对比

方式原理适用例子
关键帧动画逐帧设置属性简单机械运动门开关、平台移动
补间动画起点→终点自动插值UI、镜头、简单物体按钮弹入、相机推拉
骨骼动画骨骼带动皮肤变形角色、生物、复杂机械人走路、龙飞翔

关键帧动画

最原始的动画方式——你在时间轴上打几个点，引擎连起来：

时间轴：
  t=0s    t=1s    t=2s    t=3s
   │       │       │       │
   ▼       ▼       ▼       ▼
  位置=(0,0,0)  位置=(2,1,0)  位置=(4,0,0)  位置=(6,1,0)
  旋转=0°      旋转=90°     旋转=180°    旋转=270°

引擎自动插值中间帧：
  t=0.5s 时位置 ≈ (1,0.5,0)，旋转 ≈ 45°
// Three.js 关键帧动画（手动实现）
const keyframes = [
  { time: 0,   pos: new THREE.Vector3(0, 0, 0), rot: 0 },
  { time: 1,   pos: new THREE.Vector3(2, 1, 0), rot: Math.PI/2 },
  { time: 2,   pos: new THREE.Vector3(4, 0, 0), rot: Math.PI },
];

function updateAnimation(time) {
  // 找到当前时间在哪两个关键帧之间
  for (let i = 0; i < keyframes.length - 1; i++) {
    const kf1 = keyframes[i];
    const kf2 = keyframes[i + 1];
    if (time >= kf1.time && time <= kf2.time) {
      const t = (time - kf1.time) / (kf2.time - kf1.time);
      mesh.position.lerpVectors(kf1.pos, kf2.pos, t);
      mesh.rotation.z = kf1.rot + (kf2.rot - kf1.rot) * t;
      break;
    }
  }
}
Godot 里的关键帧：AnimationPlayer 节点，时间轴上右键"插入关键帧"，可以 anim 任何属性——位置、旋转、缩放、材质颜色、甚至自定义脚本变量。

补间动画与缓动曲线

补间（Tween）是"从 A 到 B"的自动化。关键是缓动曲线——控制中间怎么过渡：

Linear
匀速
Ease In
先慢后快
Ease Out
先快后慢
Ease InOut
两头慢中间快
Bounce
弹跳
Elastic
橡皮筋
// Three.js 用 GSAP 库做补间
gsap.to(mesh.position, {
  x: 5,
  duration: 2,
  ease: "bounce.out"  // 弹跳结束
});

// 或者手动实现 easing
function easeOutQuad(t) {
  return t * (2 - t);  // 先快后慢
}

// 应用到动画
const easedT = easeOutQuad(rawT);
mesh.position.lerpVectors(startPos, endPos, easedT);
缓动曲线是"感觉"的关键：UI 按钮用 Ease Out 显得轻快，相机移动用 Ease InOut 显得平滑，掉落物体用 Bounce 显得真实。Godot 的 Tween 节点内置所有标准缓动。

骨骼动画

角色动画不能用"整体移动"——手臂要弯、腿要迈、手指要动。解决方案：骨骼。

骨骼层级：
  脊柱
   ├── 头
   ├── 左肩
   │    └── 左臂
   │         └── 左手
   └── 右肩
        └── 右臂
             └── 右手

移动"左臂"骨骼 → 左手跟着动（层级变换）
弯曲"脊柱" → 整个上半身前倾

每个顶点绑定到一根或多根骨骼，骨骼移动时顶点跟着动（带权重混合）：

顶点权重示例（膝盖部位）：
  顶点 A：大腿骨权重 70%，小腿骨权重 30%
  顶点 B：大腿骨权重 50%，小腿骨权重 50%
  
  → 弯曲膝盖时，A 更多跟着大腿动，B 均匀过渡
  → 皮肤不会撕裂，平滑变形
骨骼动画是游戏角色动画的唯一标准。2D 游戏用序列帧（Sprite Sheet），3D 游戏全部用骨骼。Godot 的 Skeleton3D + AnimationPlayer 是完整解决方案。

动画状态机

角色不能只有"走路"一个动画——待机、跑步、跳跃、攻击、死亡……怎么切换？

状态机（State Machine）：
  
  [待机] ←→ [走路] ←→ [跑步]
     ↑         ↑
     ↓         ↓
   [跳跃]    [攻击]
     ↑
     ↓
   [死亡]（终态）

规则：
  - 待机时按方向键 → 切换到走路
  - 走路时按 Shift → 切换到跑步
  - 任何状态按空格 → 切换到跳跃
  - 跳跃落地 → 回到待机/走路/跑步
// Godot 动画状态机（AnimationTree）
// 参数：speed (0=待机, 1=走路, 2=跑步)
// 状态：idle, walk, run, jump

func _process(delta):
    var speed = Input.get_action_strength("move_right")
    if is_on_floor() and Input.is_action_just_pressed("jump"):
        $AnimationTree.set("parameters/state/current", "jump")
    elif speed > 0:
        $AnimationTree.set("parameters/speed/blend_amount", speed)

口头描述练习

🗣️ 做一个主角从待机到跑步的动画切换，怎么描述？

"用 AnimationTree 做动画状态机。根节点是 BlendSpace2D，横轴是速度（0=待机，1=走路，2=跑步），自动根据速度混合 idle/walk/run 三个动画。跳跃用 OneShot 节点，触发时覆盖下半身。攻击也是 OneShot，全身覆盖。所有过渡用 Crossfade 0.2 秒，避免硬切。速度参数从脚本传入：_process 里读 Input.get_axis，映射到 0~2 范围，用 lerp 平滑变化避免抖动。"

→ 你用了 BlendSpace（速度混合）、OneShot（覆盖动作）、Crossfade（平滑过渡）、参数驱动（脚本控制）。这就是专业级的角色动画方案。
