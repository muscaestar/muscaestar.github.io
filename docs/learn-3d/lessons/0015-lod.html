015LOD：远处的东西不用那么精细

一个角色模型 5 万三角形，站在你面前时每个细节都清晰。但他跑到 500 米外，屏幕上只占 20 个像素——你还在为他算 5 万个三角形。LOD（Level of Detail）就是解决这个问题：远看用低模，近看用高模。

核心概念

LOD Level of Detail（细节层次）

同一个物体准备多套精度的模型，根据离相机的距离自动切换。近处用高模（细节多），远处用低模（三角形少），极远处用广告牌（一张贴图）甚至不渲染。

LOD 级别 LOD0 / LOD1 / LOD2...

LOD0 是最高精度（原始模型），LOD1 减面版，LOD2 再减，最后一级通常是 billboard（面向相机的贴片）。每级三角形数大约减半。

切换距离 Transition Distance

多远换哪级。太近切换会"跳变"（popping）——模型突然变样被玩家察觉。太远切换浪费性能。调这个距离是 LOD 配置的核心工作。

LOD 的直觉

一棵树（LOD0：5000 三角形）：

  距离 10m   → 屏幕上 500 像素高 → 每片叶子都看得清 → LOD0（5000 三角形）
  距离 50m   → 屏幕上 100 像素高 → 只能看清树形轮廓 → LOD1（1500 三角形）
  距离 200m  → 屏幕上 25 像素高  → 就是一团绿       → LOD2（400 三角形）
  距离 500m  → 屏幕上 10 像素高  → 一个色点         → Billboard（2 个三角形）

关键洞察：屏幕上 20 个像素的东西，5000 个三角形和 400 个看起来一样。
省下的 4600 个三角形可以花在近处的东西上。

LOD 级别设计

级别三角形比例内容典型距离
LOD0100%原始模型，全部细节0 ~ 20m
LOD1~50%去掉小细节（纽扣、细纹）20 ~ 50m
LOD2~25%只保留大形体50 ~ 150m
LOD3~10%剪影级别150 ~ 400m
Billboard2 个三角形面向相机的贴图片400m+
经验法则：每级三角形减半，切换距离加倍。低模不需要手做——Blender 的 Decimate 修改器、Simplygon、InstaLOD 都能自动减面。

切换的艺术：不让玩家察觉

问题：跳变（Popping）

直接切换 LOD，模型会突然变样——玩家余光一扫就发现"那棵树闪了一下"。三种解决方案：

方案原理适用
硬切换直接换模型距离远、变化小、或者玩家注意力在别处
交叉淡化（Crossfade）新旧两个模型同时渲染几秒，透明度渐变过渡主流方案，成本是过渡期渲染两份
抖动过渡（Dithering）用噪点图案逐像素替换，没有透明混合比 crossfade 便宜，现代游戏常用

切换距离怎么定

依据：模型在屏幕上的高度（像素）

  屏幕高度 1080px，FOV 60°：
  2m 高的树在距离 d 处的像素高度 ≈ (2 / d) × 1000

  像素高度 > 400px → LOD0（细节可见）
  100 ~ 400px     → LOD1
  30 ~ 100px      → LOD2
  < 30px          → LOD3 / billboard

原则：切换发生在"差别看不出来"的距离

LOD 不只用于几何体

资源LOD 策略
几何体减面（本课主题）
纹理Mipmap 就是纹理的 LOD——远处自动用小图
动画远处角色降低骨骼更新频率（30fps → 10fps）
阴影远处物体不投影（castShadow = false）
粒子远处减少粒子数量或关闭
物理远处物体休眠，不做碰撞检测
LOD 是一种思想：任何"远处感知不到"的计算都可以降级或跳过。这是性能优化的通用原则——只为你能看到的东西付钱了。

Three.js 实现

// Three.js 内置 THREE.LOD
const lod = new THREE.LOD();

// 添加各级模型和切换距离
lod.addLevel(highPolyMesh, 0);      // LOD0：0m 起
lod.addLevel(midPolyMesh, 50);      // LOD1：50m 起
lod.addLevel(lowPolyMesh, 150);     // LOD2：150m 起
lod.addLevel(billboardSprite, 400); // 贴片：400m 起

scene.add(lod);

// 渲染时自动根据相机距离切换，不需要手动干预

# 引擎自动生成减面版本，运行时自动切换

# 手动控制：Project Settings → Rendering →
#   mesh_lod_threshold（屏幕像素阈值）

# 可见距离裁剪（配合 LOD 的最后一级）：
# MeshInstance3D → Visibility Range
visibility_range_begin = 0.0        # 多远开始显示
visibility_range_end = 500.0        # 多远彻底隐藏
visibility_range_fade_mode = 1      # 淡出而非硬切

口头描述练习

🗣️ 开放世界游戏的植被 LOD 方案怎么描述？

"树木做 4 级 LOD：LOD0 是 3000 面的高模（20m 内），LOD1 减到 1200 面（50m 内），LOD2 是 400 面剪影（150m 内），150m 外用 billboard 十字交叉贴片。切换用 dithering 抖动过渡避免跳变。草不做 LOD 直接按距离密度衰减——50m 外不种草。所有树木 200m 外停止阴影投射，billboard 级不做动画（不摇摆）。visibility_range_end 设 800m，再远彻底剔除。"

→ 你用了分级减面、billboard 终极简化、抖动过渡、密度衰减、阴影裁剪、动画降级、距离剔除。这就是完整的植被 LOD 方案。
