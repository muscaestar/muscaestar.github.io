013环境光照：用一张图照亮整个场景

前面学过的光照都是"灯"——方向光、点光、聚光。但真实世界里，物体还被整个环境照亮：蓝天的散射光、地面反射的光、墙壁的反弹光。这节课讲怎么把"整个环境"打包成一张图来照明——IBL（Image-Based Lighting）。

核心概念

环境光照 Image-Based Lighting (IBL)

用一张 360° 全景图（记录环境里各个方向的光）作为光源。物体表面的每个点，根据自己的朝向去全景图上取对应方向的光。效果：物体"融入"环境，而不是悬浮在虚空里。

HDRI High Dynamic Range Image

高动态范围全景图。普通照片亮度 0~1，HDRI 可以到 0~10000（太阳真实亮度）。常用的 .hdr / .exr 格式。免费资源站：Poly Haven。

反射探针 Reflection Probe

在场景某个位置拍一张 360°"照片"，附近的物体用它来做反射和环境光。室内多房间场景每个房间放一个，比全局一张图更准确。

为什么需要 IBL

没有 IBL 的场景：
  方向光 + 环境光（单色）
  → 物体被"主光"照亮，背光面是均匀的死色
  → 金属球反射的是虚空（黑色或纯色）
  → 物体看起来"贴"在场景上，不真实

有 IBL 的场景：
  360° 全景图提供各方向的光
  → 朝上的面被蓝天照亮（淡蓝）
  → 朝下的面被地面反射照亮（暖色）
  → 金属球反射出真实的环境（天空、建筑）
  → 物体"长"在环境里
直觉：你站在户外，头顶的天是蓝的，所以你的头顶被蓝光照亮；脚下的地是绿的，所以你的下巴被绿光微微照亮。IBL 就是模拟这种"四面八方都有光"的效果。

IBL 的两个部分

漫反射环境光 Diffuse IBL / Irradiance
环境对哑光表面的照明。把全景图"糊化"（预积分），每个方向的光是周围一片区域的平均。哑光物体只关心"这个方向大概多亮"。
→ 实现：全景图预滤波成极低分辨率（ irradiance map），哑光材质查一次就完事
镜面反射 Specular IBL / Reflection
环境在光滑表面的反射。不是糊的，是清晰的镜像——金属球能照出周围的景物。粗糙度越高，反射越糊。
→ 实现：全景图预滤波成多级 mipmap（不同模糊度），根据粗糙度选对应级别
同一个全景图，两种用法：

  哑光球 → 查 irradiance map（糊） → 均匀的环境色
  金属球 → 查 mipmap 反射（清晰） → 映出天空和建筑
  半粗糙球 → 查中间级 mipmap → 模糊的反射

IBL vs 传统光照

传统光照（灯）IBL（环境图）
光源几个点/方向整个 360° 环境
反射只有高光点反射出真实景物
设置成本调多盏灯丢一张图
真实感物体"悬浮"物体"融入"环境
性能每盏灯都计算预滤波，查表就行
实战搭配：IBL 管"环境基础光"（物体融入场景），方向光管"主光造型"（阴影、明暗对比）。两者结合是现代 PBR 渲染的标配——几乎所有 3D 展示网站（Sketchfab）都这么做。

Three.js 实现

import { RGBELoader } from 'three/addons/loaders/RGBELoader.js';

// 1. 加载 HDRI
const hdr = await new RGBELoader().loadAsync('studio.hdr');

// 2. 预滤波（PMREM：预计算 mipmap 反射）
const pmrem = new THREE.PMREMGenerator(renderer);
const envMap = pmrem.fromEquirectangular(hdr).texture;

// 3. 设为场景环境
scene.environment = envMap;   // 所有 PBR 材质自动获得 IBL
scene.background = envMap;    // 可选：背景也显示全景图

// 完事。MeshStandardMaterial 自动使用：
// - 哑光部分 → irradiance
// - 金属/光滑部分 → 反射

Godot 实现

# Godot 4：WorldEnvironment → Environment
# 拖入全景图就行

environment.background_mode = Environment.BG_SKY
environment.sky = Sky.new()
environment.sky.sky_material = PanoramaSkyMaterial.new()
environment.sky.sky_material.panorama = load("res://sky.hdr")

# 环境光自动生效
environment.ambient_light_source = Environment.AMBIENT_SOURCE_SKY

# 摆到房间里，附近的物体用它做反射

口头描述练习

🗣️ 做一个产品展示场景（手表特写），怎么描述光照需求？

"光照用 IBL + 主光。环境用一张摄影棚 HDRI（softbox 灯光），提供基础照明和金属表壳的反射——表壳要能映出柔和的长条灯影，这是高端手表广告的标志性反射。然后加一盏聚光灯做主光，从左上 45° 打下来，产生明确的阴影和表盘高光。背景用纯色（不是 HDRI 背景），突出产品。ACES 色调映射，曝光 1.1。"

→ 你用了 IBL、HDRI、反射内容控制、主光造型、背景分离、色调映射。这就是专业产品渲染的描述方式。
