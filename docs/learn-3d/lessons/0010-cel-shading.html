010色阶：三渲二的明暗

上节课讲了描边——三渲二的轮廓。这节课讲另一个核心：色阶（Cel Shading）——让光照变成"色块"而不是"渐变"。这是动漫风格的关键。

核心概念

色阶 Cel Shading / Toon Shading

把连续的光照强度离散化成几个等级。现实光照是平滑渐变（0.0 → 1.0），色阶是跳跃变化（0.2 / 0.5 / 0.8 / 1.0）。看起来像手绘动画的色块。

色阶级数 Cel Levels / Steps

分几档亮度。常见 2~5 级：2 级（亮/暗）最简化，3 级（亮/中/暗）最经典，5 级接近真实但仍有色块感。

过渡硬度 Transition Hardness

色阶之间的边界是硬切（一条线）还是软过渡（渐变带）。硬切更动漫，软过渡更自然。

色阶的直觉

现实光照（平滑渐变）：
  亮 ←————————————————————→ 暗
  ████████████████████████████████  ← 无限多灰度

色阶（3 级离散）：
  亮 ←—————→ 中 ←—————→ 暗
  ██████████  ██████████  ██████████  ← 只有 3 种灰度

  ↑ 亮部（受光面）
        ↑ 中间调（半受光）
              ↑ 暗部（背光面）
动漫 vs 写实：写实渲染追求"无限细节"，动漫渲染追求"概括归纳"。色阶就是把复杂光照概括成几个色块——像画家用有限的颜色表现光影。

色阶级数对比

2 级（极简）
亮 / 暗
3 级（经典）
亮 / 中 / 暗
4 级
亮 / 中亮 / 中暗 / 暗
5 级（接近真实）
亮 / 亮中 / 中 / 暗中 / 暗
级数风格适用例子
2 级极简、海报风Logo、图标、极简游戏《纪念碑谷》
3 级经典动漫大多数三渲二游戏《塞尔达传说：旷野之息》
4 级细腻动漫角色特写、剧情动画《龙珠 FighterZ》
5 级半写实风格化但保留细节《英雄联盟》部分皮肤

色阶的实现原理

标准光照 vs 色阶光照

// 标准光照（Lambert）
float NdotL = dot(normal, lightDir);  // -1 ~ 1
float intensity = max(NdotL, 0.0);    // 0 ~ 1，连续渐变

// 色阶光照（3 级）
float NdotL = dot(normal, lightDir);
float intensity = max(NdotL, 0.0);

// 离散化：floor(x * n) / n
float levels = 3.0;
float celIntensity = floor(intensity * levels) / levels;
// 结果：0, 0.33, 0.66, 1.0（只有 4 个可能值）

关键：floor() 函数

floor(x * 3) / 3 的作用：

  x = 0.0 ~ 0.33  → floor(0.0~0.99) / 3 = 0/3 = 0.0
  x = 0.33 ~ 0.66 → floor(0.99~1.98) / 3 = 1/3 ≈ 0.33
  x = 0.66 ~ 1.0  → floor(1.98~3.0) / 3 = 2/3 ≈ 0.66
  x = 1.0         → floor(3.0) / 3 = 3/3 = 1.0

连续输入 → 离散输出，这就是色阶！

过渡硬度控制

硬切（Hard Edge）

// 硬切：floor() 直接离散化，边界锐利
float celIntensity = floor(intensity * levels) / levels;

效果：
  亮 |████████| 中 |████████| 暗
     ↑ 硬边界（一条线分开）

软过渡（Soft Edge）

// 软过渡：smoothstep 平滑边界
float edge = 0.05;  // 过渡带宽度
float celIntensity = floor(intensity * levels) / levels;
float nextLevel = (floor(intensity * levels) + 1.0) / levels;
celIntensity = mix(celIntensity, nextLevel, 
                   smoothstep(nextLevel - edge, nextLevel, intensity));

效果：
  亮 |████░░░░| 中 |████░░░░| 暗
     ↑ 软边界（渐变带过渡）

对比

过渡视觉风格适用
硬切边界锐利，色块分明经典动漫、赛璐璐大多数三渲二
软过渡边界柔和，自然过渡现代动漫、半写实角色特写、细腻表现

阴影风格

色阶的"暗部"不一定是黑色——可以是任何颜色，创造不同氛围：

阴影色氛围例子
纯黑经典、强烈对比老式动画、漫画
深蓝/紫夜晚、神秘《幽灵公主》
深棕/暖色黄昏、温暖《千与千寻》
互补色艺术感、风格化《蜘蛛侠：平行宇宙》
// Godot Shader：自定义阴影色
uniform vec4 shadow_color : source_color = vec4(0.1, 0.1, 0.2, 1.0);  // 深蓝阴影

void light() {
    float NdotL = dot(NORMAL, LIGHT);
    float intensity = max(NdotL, 0.0);
    
    // 3 级色阶
    float cel = floor(intensity * 3.0) / 3.0;
    
    // 阴影处混合自定义阴影色
    vec3 final_color = mix(shadow_color.rgb, ALBEDO, cel);
    DIFFUSE_LIGHT += final_color * LIGHT_COLOR;
}

Three.js 实现

// 自定义 ShaderMaterial 实现色阶
const celMaterial = new THREE.ShaderMaterial({
  uniforms: {
    levels: { value: 3.0 },           // 色阶级数
    shadowColor: { value: new THREE.Color(0x1a1a2e) },  // 阴影色
    lightDir: { value: new THREE.Vector3(1, 1, 1).normalize() }
  },
  vertexShader: `
    varying vec3 vNormal;
    void main() {
      vNormal = normalize(normalMatrix * normal);
      gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
    }
  `,
  fragmentShader: `
    uniform float levels;
    uniform vec3 shadowColor;
    uniform vec3 lightDir;
    varying vec3 vNormal;
    
    void main() {
      float intensity = max(dot(vNormal, lightDir), 0.0);
      
      // 色阶离散化
      float cel = floor(intensity * levels) / levels;
      
      // 混合阴影色和固有色
      vec3 color = mix(shadowColor, vec3(1.0), cel);
      gl_FragColor = vec4(color, 1.0);
    }
  `
});

Godot 实现

# Godot 4：内置 Toon Shader
# StandardMaterial3D → Shading → Shading Mode → Cel
# 调整 Cel Levels 和 Cel Threshold

# 或自定义 Shader
shader_type spatial;
render_mode diffuse_toon, specular_toon;  # 内置卡通渲染

uniform float cel_levels : hint_range(2, 8) = 3.0;
uniform vec4 shadow_color : source_color = vec4(0.2, 0.2, 0.3, 1.0);

void light() {
    float NdotL = dot(NORMAL, LIGHT);
    float intensity = max(NdotL, 0.0);
    
    // 色阶
    float cel = floor(intensity * cel_levels) / cel_levels;
    
    // 阴影色混合
    vec3 base = mix(shadow_color.rgb, ALBEDO, cel);
    DIFFUSE_LIGHT += base * LIGHT_COLOR * ATTENUATION;
}

口头描述练习

🗣️ 做一个经典动漫风格的角色，怎么描述色阶需求？

"用 3 级色阶，硬切过渡，阴影色用深蓝紫（#2a2a4a）不用纯黑——这样暗部有细节不死黑。高光部分加一级额外提亮（specular 也做色阶）。整体效果：受光面亮白，中间调固有色，背光面深蓝紫，边界锐利像赛璐璐动画。参考《龙珠 FighterZ》的角色渲染。"

→ 你用了色阶级数、过渡硬度、自定义阴影色、高光色阶、参考案例。这就是专业级的色阶描述。
