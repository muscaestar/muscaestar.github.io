011完整三渲二：实战配方

描边 + 色阶 + 材质简化 = 完整三渲二。这节课把前两课的技术组装起来，给你一个可以直接用的实战配方。

三渲二的完整配方

1
描边（Outline）
Inverted Hull：复制 mesh，顶点外扩 2%，黑色背面渲染。轮廓线是三渲二的标志性特征。
2
色阶（Cel Shading）
3 级色阶，硬切过渡，阴影色深蓝紫（#2a2a4a）。离散光照创造色块感。
3
材质简化
去掉 PBR 的金属度/粗糙度变化，用平涂色（flat color）。动漫风格不需要真实材质细节。
4
可选：风格化阴影
阴影边缘加硬、阴影色偏移、或者完全去掉阴影（某些风格）。

步骤 1：描边（复习）

// Inverted Hull 描边
const outline = new THREE.Mesh(
  geometry.clone(),
  new THREE.MeshBasicMaterial({ 
    color: 0x000000, 
    side: THREE.BackSide 
  })
);
outline.scale.multiplyScalar(1.02);
scene.add(outline);
描边粗细：2% 是经典值。太细（1%）看不清，太粗（5%）像贴纸。角色特写可以 3%，远景 1%。

步骤 2：色阶（复习）

// 3 级色阶，硬切，深蓝阴影
float cel = floor(intensity * 3.0) / 3.0;
vec3 color = mix(shadowColor, baseColor, cel);
阴影色选择：深蓝紫（#2a2a4a）是万能选择——比纯黑柔和，适合大多数场景。夜晚场景用更深的蓝，黄昏用深棕。

步骤 3：材质简化

PBR 材质追求真实——金属度、粗糙度、法线细节。三渲二追求概括——平涂色，去掉细节：

PBR 材质三渲二材质原因
金属度 0~1 变化金属度 = 0（非金属）或 1（金属）动漫里金属就是亮，非金属就是哑光
粗糙度 0~1 变化粗糙度 = 0.8（统一）不需要细微变化，统一即可
法线贴图（细节）不用法线贴图色阶已经概括了光影，不需要微观凹凸
AO 贴图（缝隙阴影）可选，或烘焙到阴影色简化光影，减少真实感
// 三渲二材质设置
const toonMaterial = new THREE.MeshToonMaterial({
  color: 0xff6b6b,        // 平涂色
  // 不用 metalness/roughness 变化
  // 不用 normalMap
  // 不用 aoMap（或烘焙到颜色里）
});

硬阴影

// 标准阴影是软边（PCF 模糊）
// 三渲二用硬边阴影（一条线分开）

// Three.js：调 shadow radius
light.shadow.radius = 0;  // 0 = 硬边

// Godot：Shadow → Quality → Hard

阴影色偏移

// 阴影不是黑色，而是有色
// 比如：阳光下的阴影偏蓝，火光下的阴影偏红

// 在 Shader 里混合：
vec3 shadowTint = vec3(0.8, 0.9, 1.0);  // 偏蓝
vec3 shadowColor = mix(baseColor * 0.3, shadowTint, 0.3);

完整 Three.js 实现

// 1. 创建角色（简化材质）
const character = new THREE.Group();

const bodyMat = new THREE.MeshToonMaterial({ color: 0xff6b6b });
const headMat = new THREE.MeshToonMaterial({ color: 0xffd93d });

const body = new THREE.Mesh(bodyGeo, bodyMat);
const head = new THREE.Mesh(headGeo, headMat);
character.add(body, head);
scene.add(character);

// 2. 描边（Inverted Hull）
const outlineGroup = new THREE.Group();
character.children.forEach(child => {
  const outline = new THREE.Mesh(
    child.geometry.clone(),
    new THREE.MeshBasicMaterial({ 
      color: 0x000000, 
      side: THREE.BackSide 
    })
  );
  outline.scale.multiplyScalar(1.02);
  outline.position.copy(child.position);
  outlineGroup.add(outline);
});
scene.add(outlineGroup);

// 3. 灯光（简单平行光）
const light = new THREE.DirectionalLight(0xffffff, 1.0);
light.position.set(5, 5, 5);
scene.add(light);

// 4. 渲染（MeshToonMaterial 自动做色阶）
// 不需要自定义 Shader！
Three.js 的 MeshToonMaterial：内置卡通渲染，自动做 3 级色阶。不需要写 Shader，直接换材质就行。渐变贴图（gradientMap）可以自定义色阶。

完整 Godot 实现

# 1. 材质：StandardMaterial3D + Toon 模式
var mat = StandardMaterial3D.new()
mat.shading_mode = StandardMaterial3D.SHADING_MODE_CEL
mat.cel_levels = 3
mat.cel_threshold = 0.5
mat.albedo_color = Color(1, 0.4, 0.4)  # 平涂色

# 2. 描边：Next Pass
var outline = StandardMaterial3D.new()
outline.albedo_color = Color.BLACK
outline.cull_mode = StandardMaterial3D.CULL_FRONT
outline.shading_mode = StandardMaterial3D.SHADING_MODE_UNSHADED
mat.next_pass = outline

# 3. 灯光：DirectionalLight3D
# 调整 shadow 为硬边（Project Settings → Rendering → Quality → Shadows）

# 4. 完成！Godot 自动处理色阶和描边
