017程序化生成：用算法种出世界

《我的世界》有 18 亿亿个方块的地形，《无人深空》有 18 万亿颗星球——显然不是美术手摆的。它们是程序化生成（Procedural Generation）：写一套规则，让算法自动种出世界。

核心概念

程序化生成 Procedural Generation (PCG)

用算法而不是手工创建内容。地形、植被、迷宫、任务、名字——只要你能写出规则，就能自动生成。核心优势：无限内容、小存储、可复现。

随机种子 Random Seed

程序化生成的"世界编号"。同一个种子生成的世界完全一样——所以《我的世界》可以分享种子码，别人输入后得到一模一样的世界。

噪声函数 Noise Function

程序化生成的核心工具。不是纯随机（白噪声，杂乱无章），而是"平滑的随机"——相邻位置的值相近，远处才不同。像山的高度：相邻两点高度差不多，拉开距离才有起伏。

噪声：从随机到自然

纯随机（白噪声）：
  每 个 点 都 乱 跳 —— 像 电 视 雪 花
  做地形：尖刺密布，完全不像山

平滑噪声（Perlin/Simplex）：
  相邻点平滑过渡 —— 像 起 伏 的 布
  做地形：有山坡有山谷，自然

关键性质：
  1. 连续性：相邻位置值相近
  2. 确定性：同一个坐标永远得到同一个值
  3. 无周期性：不会看出重复图案（理想情况）

分形叠加：一层噪声不够

单层噪声太"规则"——都是同样大小的起伏。真实地形有大山脉，山脉上有小山坡，山坡上有碎石。解决：叠加多层不同频率的噪声。

分形噪声（fBm, Fractal Brownian Motion）：

  最终高度 = 
      noise(x, y) × 1.0      ← 低频大幅：大山脉
    + noise(x×2, y×2) × 0.5  ← 中频中幅：山坡起伏
    + noise(x×4, y×4) × 0.25 ← 高频小幅：表面粗糙
    + noise(x×8, y×8) × 0.125

  每层频率 ×2，振幅 ÷2（叫 octave 八度）

  4~6 层叠加 → 既有大结构又有小细节 → 自然
这个思想无处不在：地形高度、云层形状、水面波纹、火焰抖动、材质纹理——都是"低频定大形，高频加细节"。以后看到任何"自然感"的程序纹理，猜 fBm 八九不离十。

从噪声到世界：完整管线

以生成分岛为例：

1. 高度图：fBm 噪声 → 每个格子的海拔
2. 地形分类：按高度分层
     < 0.3  深水
     < 0.4  浅水
     < 0.5  沙滩
     < 0.7  草地
     < 0.85 森林
     ≥ 0.85 雪山
3. 湿度图：另一张噪声（不同种子）→ 决定植被密度
4. 撒物件：森林格子上按湿度随机撒树（泊松盘采样，防止挤一起）
5. 河流：从山顶沿梯度下降走到海（A* 或简单下坡）

常用生成算法速查

算法生成什么核心思想
Perlin/Simplex 噪声地形高度、云、纹理平滑随机 + 分形叠加
Worley/Voronoi细胞纹理、碎裂地块、蜂窝到最近特征点的距离
L-system植物、树、分形字符串重写规则递归展开
波函数坍缩（WFC）地图、关卡、像素画局部约束传播（像解数独）
元胞自动机洞穴、地牢格子按邻居规则演化几代
泊松盘采样撒树、撒石头随机但保持最小间距
迷宫算法地牢递归分割/回溯/Prim

种子：可复现的魔法

伪随机数生成器（PRNG）：
  seed = 42
  random() → 0.374  （永远是 0.374）
  random() → 0.891  （永远是 0.891）

同一个种子 → 同一串"随机"数 → 同一个世界

好处：
  1. 分享：发种子码 = 发整个世界
  2. 存储：不用存地图，只存一个数字
  3. 流式加载：玩家走到哪里，现场算哪里
     （《我的世界》从不存完整地图，只存玩家改过的部分）
确定性是双刃剑：所有客户端必须用同一个算法同一个种子，否则联机时每个人看到的世界不一样。改一行噪声代码 = 所有人的世界全变。所以生成算法要版本化。

手工 + 程序化的混合

纯程序化容易"千篇一律"（算法味太重），实际项目都是混合：

层级谁做例子
大结构手工设计主城位置、剧情关卡、地标
中结构程序生成 + 手工规则地形起伏、道路走向、村落布局
小细节纯程序化草、石头、树的精确位置
《塞尔达传说：旷野之息》的做法：地形大体手工雕琢（保证玩法设计），但植被、石头、蘑菇这类填充物按规则自动撒。美术画"规则"（这里该长什么），程序管"执行"。

Three.js 实现（地形）

// Simplex 噪声库：three/addons/math/SimplexNoise.js
import { SimplexNoise } from 'three/addons/math/SimplexNoise.js';

const noise = new SimplexNoise();
const geo = new THREE.PlaneGeometry(100, 100, 128, 128);
const pos = geo.attributes.position;

for (let i = 0; i < pos.count; i++) {
  const x = pos.getX(i), y = pos.getY(i);
  let h = 0, freq = 0.02, amp = 10;
  for (let o = 0; o < 4; o++) {          // 4 层分形
    h += noise.noise(x * freq, y * freq) * amp;
    freq *= 2; amp *= 0.5;
  }
  pos.setZ(i, h);
}
geo.computeVertexNormals();

🗣️ 生存游戏的岛屿生成方案怎么描述？

"地形用 5 层 fBm Simplex 噪声，叠加径向衰减（离中心越远越低）保证是岛。生物群系按高度+湿度双噪声分：低海拔湿地、中海拔森林、高海拔岩石。树用泊松盘撒，密度由湿度图控制，海滩不撒。河流从最高点沿梯度下降画到海，两岸自动铺沙。资源点（矿石、浆果丛）用 Worley 噪声的细胞中心定位，保证分布均匀不扎堆。全局一个种子，联机时主机发给客户端。村庄和副本入口手工标记位置，写进种子配置里覆盖生成结果。"

→ 你用了 fBm、径向衰减、双噪声群系、泊松盘、梯度河流、Worley 资源点、种子同步、手工覆盖。这就是完整的岛屿生成方案。
