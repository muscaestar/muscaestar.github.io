020体积效果：雾、云和光柱

远处群山在雾中变淡、手电光束在黑暗中可见、云在天上飘——这些都涉及"光在介质中传播"，也就是体积效果。真实模拟太贵，所以游戏用的是层层递进的近似。

核心概念

体积效果 Volumetric Effects

普通渲染只算表面，体积效果考虑光穿过介质（雾/云/烟）的路径——光在介质里被吸收、散射、自发光，"看到的不只是表面，还有表面之间的空气"。

Ray Marching 射线步进

体积效果的核心算法：从相机向场景发射线，沿射线每步采样介质密度，累加光的贡献。步数越多越准越贵。这是体积云、体积雾、体积光的通用框架。

大气散射 Atmospheric Scattering

天空为什么是蓝的？日落为什么是红的？—— 瑞利散射（短波蓝光散射多）+ 米氏散射（大颗粒，各种波长都散）。大气散射是天空渲染的物理基础。

从便宜到贵的体积方案

方案原理成本适合
高度雾按片元世界高度混合雾色几乎免费山谷低雾、地牢氛围
距离雾按相机距离混合雾色几乎免费通用远景雾、隐藏远景加载
光柱贴图面片+渐隐贴图模拟光束便宜舞台灯光、窗户光斑
Billboard 云面向相机的面片+云贴图便宜远景云、静态天空
体积光（Ray March）沿射线步进采样，累加散射中手电光束、教堂彩窗光
体积云（3D 噪声 + Ray March）3D 噪声定义密度场，步进采样贵飞行游戏、天气系统
大气散射完整大气模型，太阳/天空/雾统一贵开放世界、飞行模拟
大多数游戏混用：距离雾管远景，光柱贴图管局部光束，billboard 云管远景云，只在飞行镜头才用真体积云。根据镜头需求选方案。

距离雾：最基础也最重要

所有游戏引擎都内置距离雾，因为它同时做两件事：

功能说明
氛围远山变淡、远景模糊——"空气透视"，给场景深度感
遮丑隐藏远景 LOD 切换、场景加载边界、视野尽头
// 线性雾：start~end 之间从 0% 到 100% 雾
scene.fog = new THREE.Fog(0x88aacc, 10, 100);

// 指数雾：浓度随距离指数增长，更自然
scene.fog = new THREE.FogExp2(0x88aacc, 0.03);

// 雾色选择 = 氛围的灵魂
// 白天：浅蓝灰 | 黄昏：橙红 | 夜晚：深蓝黑 | 地牢：绿黑
雾色比雾参数更重要。同样的密度，蓝雾是清晨、橙雾是沙尘暴、绿雾是毒气。调雾先调颜色，再调浓度。

体积光：手电和教堂光

真实的光束是光在雾中散射的结果。游戏里的做法：

方法原理效果
锥体贴图圆锥 mesh + 渐隐贴图，Additive 混合便宜但假，转角穿帮
屏幕空间 Ray March后处理中沿视线步进，累加光源贡献真光束，有遮挡，较贵
体积阴影贴图光源视角渲染深度，步进时查阴影光束被物体挡住，真实但最贵
// 屏幕空间体积光原理（后处理 fragment shader）
// 从相机到片元沿视线步进 N 步
for (int i = 0; i < N; i++) {
  vec3 p = camera + ray * t[i];
  float light = 光源强度(p) * 衰减(p);
  accum += light;
}
// 累加结果就是这条视线上看到的"光的总量"

体积云：最贵的体积效果

真正的云是 3D 密度场，需要 ray marching 采样。简化版：

// 3D 噪声定义云的密度场
float cloudDensity(vec3 p) {
  float base = fbm3d(p * 0.01);           // 大形状
  float detail = fbm3d(p * 0.05) * 0.3;   // 细节
  return max(0, base + detail - coverage); // coverage 控制云量
}

// Ray marching：沿视线步进，密度高的地方吸收/散射光
vec4 marchCloud(vec3 origin, vec3 dir) {
  vec4 result = vec4(0);
  for (float t = 0; t < maxDist; t += step) {
    vec3 p = origin + dir * t;
    float d = cloudDensity(p);
    if (d > 0) {
      // 向光源方向再步进，算云的透光性
      float light = marchLight(p);
      result.rgb += cloudColor * d * light;
      result.a += d * (1 - result.a);
    }
  }
  return result;
}
手机平台的云策略：远景 billboard + 头顶少量 3D 噪声云 + 雾衔接。全场景 ray marching 体积云在手机上是帧率杀手。大多数"飞行游戏"的云其实是精心布置的 billboard 序列。

大气散射：天空渲染的物理

为什么天是蓝的、日落是红的：

散射类型颗粒效果
瑞利散射分子（极小）短波（蓝光）散射多 → 天蓝
米氏散射尘埃水滴（大）各波长都散 → 云白、雾灰
日落红的原理：
正午：光垂直穿过大气 → 路径短 → 蓝光散射掉一些，但还是蓝
日落：光斜穿大气 → 路径长 → 蓝光全散光了 → 剩下红光到眼睛
实用价值：不需要手写大气散射——引擎（Unreal/Unity/Godot 4）都内置了物理天空。但理解原理后你就知道：想"黄昏感"就增大光学厚度（调 atmosphere thickness），想"异星天空"就改瑞利系数（变成紫色天空）。

Godot 实现

# Godot 4 的体积雾：WorldEnvironment 节点
extends WorldEnvironment

func _ready():
    var env = Environment.new()
    env.background_mode = Environment.BG_SKY
    
    # 体积雾
    env.volumetric_fog_enabled = true
    env.volumetric_fog_density = 0.05
    env.volumetric_fog_albedo = Color(0.8, 0.8, 0.8)
    
    # 雾
    env.fog_enabled = true
    env.fog_light_color = Color(0.6, 0.7, 0.8)
    env.fog_density = 0.01
    
    environment = env

# 体积光：SpotLight3D 开 shadow + volumetric_fog 自然出光束
# 无需特殊设置，引擎自动算

🗣️ 开放世界手游的体积效果方案怎么描述？

"分层方案：全局用距离雾管远景，雾色按天气系统切换（晴天浅蓝/雨天灰/沙尘橙），浓度随时间变化（清晨浓正午淡）。局部光源（手电/车灯/路灯）用锥体贴图+渐隐，便宜且可控。云用远景 billboard 序列+头顶 3D 噪声云——飞行高度低时 billboard 足够，高时切换真体积云。大气散射用引擎内置物理天空，调光学厚度做黄昏。手机端：体积光只给主角手电，NPC 用普通点光，远景雾密度比 PC 高 20% 掩盖更多 LOD 切换。"

→ 你用了分层方案、天气联动、锥体贴图、混合云策略、手机降级。这就是真实的开放世界体积方案。
